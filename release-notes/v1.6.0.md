## GeoStamp Camera v1.6.0 — Location in your photo file names

You can now choose what goes into the file name of every saved photo, so photos sort and search by place, not just by time.

### Photo file names
- New **Settings → General → Photo file name**.
- Add, remove and reorder fields: prefix text, date & time, date only, coordinates, Plus Code, altitude, place, short address, country code, project/site, person name, custom field 1 and photo number.
- A live preview shows the exact name as you change it, for example `GeoStamp_20261127_093012_481_28.61390N_77.20900E_7JWVJ6M5+H2.jpg`.
- One-tap presets: Default, Coordinates, Plus Code, Survey and Place. Choose `_` or `-` as the separator.
- Coordinates use N/S/E/W letters with about 1 m precision. The Plus Code is worked out from the coordinates when the address lookup hasn't returned yet.
- Names are cleaned for any file system: letters in any language are kept, while spaces, commas and characters like `/ : * ?` become `-`. Names stay under the length limit.
- Fields without a value are skipped. Two photos never overwrite each other; a number is added if a name repeats.
- Applies to camera shots, bursts, timelapse frames, gallery stamping and kept originals (which now share their stamped photo's name).
- If you don't change anything, photos keep the same names as before.

### Install
Download **GeoStamp-Camera-v1.6.0.apk** below (Android 8.0+ / API 26 to Android 16 / API 36).

If Android refuses to install it over an older version with a "package conflicts" or signature error, uninstall the old version first. Photos you already saved stay in your gallery.
