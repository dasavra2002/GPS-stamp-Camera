## GeoStamp Camera v1.4.0 — Verifiable photos and a cleaner camera

This release makes the location stamp something you can actually check, keeps your camera metadata intact, and tidies up the camera, settings, gallery and verify screens.

### Signed, verifiable photos
- Every saved photo now carries a signed capture proof in its metadata: coordinates, accuracy, time, photo number, location source and a SHA-256 of the image data, signed with an ECDSA P-256 key held in the phone's Android Keystore (StrongBox or TEE). The key's hardware attestation chain is stored alongside it.
- New **Gallery > Verify photo** screen checks the signature, that the pixels are unchanged, that the key was created in genuine Android hardware for this app, and whether the bootloader is locked. Edits, crops, re-compression or changed metadata fail verification.
- The QR code on the stamp is now a readable summary (map link, coordinates, time). It replaces the old hardcoded-secret "tamper-proof" code, which did not protect the image.

### More trustworthy location
- Warns when the location comes from a mock-location app, is stale, or is inaccurate at the moment you press the shutter, and records that in the proof.
- Fixes from an external Bluetooth GNSS / RTK receiver are no longer overwritten by the phone's own GPS.

### Photo files
- Original camera EXIF (ISO, exposure, lens and so on) is kept on stamped photos, with GPS time and accuracy tags added.
- Optional setting to also keep the unstamped original.

### Offline maps
- Offline map packs only download from servers that allow bulk downloading. Set a custom tile server (MapTiler, Thunderforest, Stadia or self-hosted) to use them. Maps on stamps still use the public servers, and frame-style watermarks now print the map attribution.

### UI polish
- The gold GeoStamp palette is used on every phone instead of wallpaper-derived colours.
- Camera: consistent translucent controls with 44dp touch targets, icons instead of emoji, a centred shutter that animates between start/stop and shows a progress ring while saving, readable mode names, and one share button.
- Settings: section headers, shorter titles, switches throughout, and long values that no longer squeeze their labels. The About card shows the installed version.
- Gallery: empty state, status pill, and an action row that fits small phones.
- Verify dialog: verdict icon, clearer passed/failed checks.

### Under the hood
- CI runs the unit tests on every push and pull request, and builds this release from the tag.
- The capture-and-save pipeline is shared between single shots and time-lapse frames.
- README corrected to match what the app actually does.

### Install
Download **GeoStamp-Camera-v1.4.0.apk** below (Android 8.0+ / API 26 to Android 16 / API 36).

If Android refuses to install it over an older version with a "package conflicts" or signature error, uninstall the old version first. Photos you already saved stay in your gallery.
